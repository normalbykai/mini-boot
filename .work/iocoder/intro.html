# 信创兼容与数据库支持

支持国产操作系统、数据库和中间件，满足信创环境的部署需要：

类别 支持 说明
国产操作系统 银河麒麟、统信 UOS 等 Linux 系统 参考 《Linux 部署》，选择与 CPU 架构匹配的 JDK
关系型数据库 MySQL、MariaDB、Oracle、PostgreSQL、SQL Server 默认使用 MySQL
国产关系型数据库 达梦 DM、人大金仓 KingbaseES、openGauss、瀚高 HighGo、OceanBase、TiDB、华为 GaussDB、云和恩墨 MogDB、海量 Vastbase G100、PolarDB、神通 参考 《国产信创数据库》。GaussDB、MogDB、Vastbase G100 使用 PG 兼容模式；神通已支持普通 CRUD、代码生成、Quartz、Flowable（master-jdk17 分支），详见 神通数据库
国产缓存 东方通 TongRDS、宝兰德 BES CacheDB 替换 Redis，参考 《国产信创数据库》。BES CacheDB 提供接入说明，待介质验证
国产应用服务器 东方通 TongWeb、宝兰德 BES AppServer 替换 Tomcat，参考 《东方通服务器部署》、《宝兰德服务器部署》。BES AppServer 提供接入说明，待介质验证
国产 Web 服务器 东方通 TongHttpServer 替换 Nginx，提供静态资源、反向代理，参考 《东方通服务器部署》
  • 数据库脚本：项目 sql (opens new window) 目录提供 MySQL、Oracle、PostgreSQL、SQL Server、达梦、人大金仓、openGauss、瀚高、OceanBase 的项目初始化脚本（含 Quartz），优先使用对应目录；MariaDB、TiDB 直接使用 MySQL 脚本；GaussDB、MogDB、Vastbase G100 基于 openGauss 脚本导入，PolarDB PostgreSQL 版直接使用 PostgreSQL 脚本；神通需按 文档 调整 openGauss 项目脚本（含 Quartz）后导入
  • 其它数据库、后续表结构变更，可参考 sql/tools (opens new window) 的转换工具及 《表结构变更（版本升级）》，转换后仍需按实际数据库调整、测试
